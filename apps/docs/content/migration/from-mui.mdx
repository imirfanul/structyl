# Migrating from MUI

`aura-ui` is Tailwind-styled and headless — quite different from MUI's emotion-based theming. The migration is mostly a styling rewrite.

## Theming

- **MUI:** `<ThemeProvider theme={createTheme(...)}>` with emotion in the background.
- **aura-ui:** `<ThemeProvider theme="slate">` (or your custom theme) consumed via CSS variables. No CSS-in-JS at runtime.

## Component map

| MUI                          | aura-ui                                              |
| ---------------------------- | ----------------------------------------------------- |
| `Button`                     | `Button`                                              |
| `TextField`                  | `Input` (+ `Label` + `Form` for validation)           |
| `Select`                     | `Select`                                              |
| `Dialog`                     | `Dialog`                                              |
| `Drawer`                     | `Sheet` (side) or `Drawer` (bottom)                   |
| `Snackbar`                   | `Toast`                                               |
| `Autocomplete`               | `Combobox`                                            |
| `DataGrid`                   | `DataTable`                                           |
| `Tabs`                       | `Tabs`                                                |
| `Accordion`                  | `Accordion`                                           |
| `Menu`                       | `DropdownMenu`                                        |
| `Tooltip`                    | `Tooltip`                                             |
| `Popover`                    | `Popover` (or `HoverCard` for hover-triggered)        |

## Styling differences

- All styles are Tailwind utility classes — pass them via `className`.
- For overrides, prefer composing `cn(...)` over `sx={{}}`.
- For variants, use `tailwind-variants` (`tv`) instead of MUI's `variants`.
