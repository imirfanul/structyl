# DateTimePicker

MUI-style date and time picker with one value, shared validation and a date-first flow. After the user picks a date, the popover swaps to the time picker so the time is selected as a separate step.

## Installation

```bash
npx aura-ui add date-time-picker
```

## Usage

```tsx
import { DateTimePicker } from '@aura-ui/styled';

export function Example() {
  return (
    <DateTimePicker
      label="Deployment window"
      value={dateTime}
      onChange={setDateTime}
      minDateTime={new Date(2026, 4, 20, 9, 0)}
      maxDateTime={new Date(2026, 5, 30, 18, 0)}
      minutesStep={15}
      format="MM/dd/yyyy HH:mm"
      helperText="Select a date first, then choose the time."
    />
  );
}
```

## API Reference

Supports the MUI DateTimePicker-style prop surface: `value`, `defaultValue`, `onChange`, `onAccept`, `onError`, `open`, `views`, `view`, `openTo`, `minDateTime`, `maxDateTime`, `minDate`, `maxDate`, `minTime`, `maxTime`, `ampm`, `minutesStep`, `timeSteps`, validation callbacks, loading props, slots, slotProps and `sx`. The default styled picker shows the calendar first, then shows the time picker after date selection.

## Accessibility

The calendar uses grid semantics. The default time panel uses analog clock number buttons with Cancel/OK actions, while the compound `DateTimePicker.Segment` primitive remains available for spinbutton-style custom layouts.
