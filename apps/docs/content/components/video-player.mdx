# Video Player

A fully-featured HTML5 video player built on `@structyl/video-player`. Supports playlists, chapter markers, SRT/VTT subtitles, video filters, quality selection, HLS streaming, and keyboard shortcuts. Colors are driven entirely by `@structyl/themes` CSS tokens so the player respects your configured theme.

## Installation

```bash
pnpm add @structyl/video-player
```

## Usage

```tsx
import { VideoPlayer } from '@structyl/video-player';
import '@structyl/video-player/styles.css';

export function Example() {
  return (
    <VideoPlayer
      src="https://example.com/video.mp4"
      poster="https://example.com/poster.jpg"
    />
  );
}
```

## HLS Streaming

Pass an `.m3u8` URL as `src` — the player detects it automatically and initialises hls.js:

```tsx
<VideoPlayer src="https://example.com/stream.m3u8" />
```

## Accessibility

All control buttons are keyboard-navigable. The player supports a full keyboard shortcut set (Space, arrow keys, M, F, P, C, comma, period). Interactive elements carry appropriate ARIA labels.

## Theming

The player imports structural CSS from `@structyl/video-player/styles.css`. All color values reference `@structyl/themes` CSS tokens (`--color-primary`, `--color-fg`, `--color-border`, etc.). Wrap your application in `<ThemeProvider>` to enable runtime theme switching.
