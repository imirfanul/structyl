# Avatar

User avatar with image, fallback, and loading states.

## Installation

```bash
npx structyl add avatar
```

## Usage

```tsx
import { Avatar } from '@structyl/styled';

export function Example() {
  return <Avatar />;
}
```

## API Reference

See the [primitive types](https://github.com/your-org/structyl/tree/main/packages/primitives/src/avatar) for the full prop surface. Styled wrappers extend the primitive types with `className` and theme-aware styles.

## Accessibility

Follows the relevant [WAI-ARIA APG pattern](https://www.w3.org/WAI/ARIA/apg/patterns/). All interactive controls are keyboard-navigable and screen-reader-friendly out of the box.

## Theming

Styles consume CSS variables from `@structyl/themes` (`--bg`, `--fg`, `--primary`, `--border`, etc.). Wrap your app in `<ThemeProvider>` to enable runtime theme switching.
