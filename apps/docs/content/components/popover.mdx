# Popover

Floating content anchored to a trigger.

## Installation

```bash
npx your-lib add popover
```

## Usage

```tsx
import { Popover } from '@your-lib/styled';

export function Example() {
  return <Popover />;
}
```

## API Reference

See the [primitive types](https://github.com/your-org/your-lib/tree/main/packages/primitives/src/popover) for the full prop surface. Styled wrappers extend the primitive types with `className` and theme-aware styles.

## Accessibility

Follows the relevant [WAI-ARIA APG pattern](https://www.w3.org/WAI/ARIA/apg/patterns/). All interactive controls are keyboard-navigable and screen-reader-friendly out of the box.

## Theming

Styles consume CSS variables from `@your-lib/themes` (`--bg`, `--fg`, `--primary`, `--border`, etc.). Wrap your app in `<ThemeProvider>` to enable runtime theme switching.
