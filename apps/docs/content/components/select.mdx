# Select

A custom dropdown select with keyboard support, optional search, creation, and virtualized options for large lists.

## Installation

```bash
npx aura-ui add select
```

## Usage

```tsx
import * as React from 'react';
import { Select } from '@aura-ui/styled';

export function Example() {
  const [options, setOptions] = React.useState([
    { value: 'react', label: 'React' },
    { value: 'vue', label: 'Vue' },
    { value: 'svelte', label: 'Svelte' },
  ]);

  return (
    <Select.Root
      searchable
      onCreateOption={(value) => setOptions((current) => [{ value, label: value }, ...current])}
    >
      <Select.Trigger className="w-[260px]">
        <Select.Value placeholder="Search options" />
      </Select.Trigger>
      <Select.Content options={options} />
    </Select.Root>
  );
}
```

## API Reference

See the [primitive types](https://github.com/your-org/aura-ui/tree/main/packages/primitives/src/select) for the full prop surface. Styled wrappers extend the primitive types with `className` and theme-aware styles.

## Accessibility

Follows the relevant [WAI-ARIA APG pattern](https://www.w3.org/WAI/ARIA/apg/patterns/). All interactive controls are keyboard-navigable and screen-reader-friendly out of the box.

## Theming

Styles consume CSS variables from `@aura-ui/themes` (`--bg`, `--fg`, `--primary`, `--border`, etc.). Wrap your app in `<ThemeProvider>` to enable runtime theme switching.
