# CircularProgress

Circular spinner with determinate and indeterminate modes.

## Installation

```bash
npx aura-ui add circular-progress
```

## Usage

```tsx
import { CircularProgress } from '@aura-ui/styled';

export function Example() {
  return <CircularProgress />;
}
```

## API Reference

See the [primitive types](https://github.com/your-org/aura-ui/tree/main/packages/primitives/src/circular-progress) for the full prop surface. Styled wrappers extend the primitive types with `className` and theme-aware styles.

## Accessibility

Follows the relevant [WAI-ARIA APG pattern](https://www.w3.org/WAI/ARIA/apg/patterns/). All interactive controls are keyboard-navigable and screen-reader-friendly out of the box.

## Theming

Styles consume CSS variables from `@aura-ui/themes` (`--bg`, `--fg`, `--primary`, `--border`, etc.). Wrap your app in `<ThemeProvider>` to enable runtime theme switching.
