# DatePicker

MUI-style calendar field for date selection. Supports controlled values, validation, loading states, view props, formatting and compound composition.

## Installation

```bash
npx aura-ui add date-picker
```

## Usage

```tsx
import { DatePicker } from '@aura-ui/styled';

export function Example() {
  return (
    <DatePicker
      label="Release date"
      value={date}
      onChange={(nextDate, context) => {
        setDate(nextDate);
        console.log(context.validationError);
      }}
      minDate={new Date(2026, 4, 1)}
      maxDate={new Date(2026, 5, 30)}
      format="MM/dd/yyyy"
      disablePast
    />
  );
}
```

## API Reference

See the [primitive types](https://github.com/your-org/aura-ui/tree/main/packages/primitives/src/date-picker) for the full prop surface. Styled wrappers extend the primitive types with `className` and theme-aware styles.

## Accessibility

Follows the relevant [WAI-ARIA APG pattern](https://www.w3.org/WAI/ARIA/apg/patterns/). All interactive controls are keyboard-navigable and screen-reader-friendly out of the box.

## Theming

Styles consume CSS variables from `@aura-ui/themes` (`--bg`, `--fg`, `--primary`, `--border`, etc.). Wrap your app in `<ThemeProvider>` to enable runtime theme switching.
