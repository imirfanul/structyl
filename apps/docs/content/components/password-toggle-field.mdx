# PasswordToggleField

Password input with show/hide toggle.

## Installation

```bash
npx your-lib add password-toggle-field
```

## Usage

```tsx
import { PasswordToggleField } from '@your-lib/styled';

export function Example() {
  return <PasswordToggleField />;
}
```
