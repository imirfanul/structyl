# DataTable

A full-featured data grid with sorting, filtering, virtualization, and export.

## Installation

```bash
npx aura-ui add data-table
```

## Usage

```tsx
import { DataTable } from '@aura-ui/styled';

export function Example() {
  return <DataTable />;
}
```

## API Reference

See the [primitive types](https://github.com/your-org/aura-ui/tree/main/packages/primitives/src/data-table) for the full prop surface. Styled wrappers extend the primitive types with `className` and theme-aware styles.

## Accessibility

Follows the relevant [WAI-ARIA APG pattern](https://www.w3.org/WAI/ARIA/apg/patterns/). All interactive controls are keyboard-navigable and screen-reader-friendly out of the box.

## Theming

Styles consume CSS variables from `@aura-ui/themes` (`--bg`, `--fg`, `--primary`, `--border`, etc.). Wrap your app in `<ThemeProvider>` to enable runtime theme switching.
