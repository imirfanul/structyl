# TagsInput

Tag input with chips, delimiters, and paste-split.

## Installation

```bash
npx structyl add tags-input
```

## Usage

```tsx
import { TagsInput } from '@structyl/styled';

export function Example() {
  return <TagsInput />;
}
```

## API Reference

See the [primitive types](https://github.com/your-org/structyl/tree/main/packages/primitives/src/tags-input) for the full prop surface. Styled wrappers extend the primitive types with `className` and theme-aware styles.

## Accessibility

Follows the relevant [WAI-ARIA APG pattern](https://www.w3.org/WAI/ARIA/apg/patterns/). All interactive controls are keyboard-navigable and screen-reader-friendly out of the box.

## Theming

Styles consume CSS variables from `@structyl/themes` (`--bg`, `--fg`, `--primary`, `--border`, etc.). Wrap your app in `<ThemeProvider>` to enable runtime theme switching.
