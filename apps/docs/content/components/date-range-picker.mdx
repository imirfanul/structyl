# DateRangePicker

MUI-style range picker with tuple values, validation, multiple calendars and shortcut action buttons.

## Installation

```bash
npx aura-ui add date-range-picker
```

## Usage

```tsx
import { DateRangePicker } from '@aura-ui/styled';

export function Example() {
  return (
    <DateRangePicker
      label="Report period"
      value={range}
      onChange={setRange}
      calendars={2}
      shortcuts={[
        { label: 'Last 7 days', getValue: (today) => [addDays(today, -6), today] },
        { label: 'Last 30 days', getValue: (today) => [addDays(today, -29), today] },
      ]}
    />
  );
}
```

## API Reference

See the [primitive types](https://github.com/your-org/aura-ui/tree/main/packages/primitives/src/date-range-picker) for the full prop surface. Styled wrappers extend the primitive types with `className` and theme-aware styles.

## Accessibility

Follows the relevant [WAI-ARIA APG pattern](https://www.w3.org/WAI/ARIA/apg/patterns/). All interactive controls are keyboard-navigable and screen-reader-friendly out of the box.

## Theming

Styles consume CSS variables from `@aura-ui/themes` (`--bg`, `--fg`, `--primary`, `--border`, etc.). Wrap your app in `<ThemeProvider>` to enable runtime theme switching.
