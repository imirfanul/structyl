# Support

Thanks for using structyl! Here's how to get help, depending on what you need.

## 📚 Start with the docs

Most questions are answered in the documentation:

- **[Documentation](https://www.structyl.com/docs)** — components, examples, and the full API reference
- **[Getting started](https://www.structyl.com/docs/getting-started)** — install and render your first component
- **[Theming](https://www.structyl.com/docs/themes)** — runtime themes and design tokens
- **[Accessibility](https://www.structyl.com/docs/accessibility)** — keyboard and screen-reader support

## 💬 Questions & usage help

For "how do I…" questions, usage help, or to share what you built, use
**[GitHub Discussions](https://github.com/imirfanul/structyl/discussions)**.
If Discussions isn't available, open a regular issue and we'll help.

Please don't open a bug issue for usage questions — Discussions get answered
faster and stay searchable for the next person.

## 🐞 Bugs & feature requests

- **Found a bug?** [Open a bug report](https://github.com/imirfanul/structyl/issues/new?template=bug_report.yml). A minimal reproduction (StackBlitz, CodeSandbox, or a small repo) is the single most helpful thing you can include.
- **Have an idea?** [Open a feature request](https://github.com/imirfanul/structyl/issues/new?template=feature_request.yml).
- **Docs unclear or wrong?** [Open a documentation issue](https://github.com/imirfanul/structyl/issues/new?template=documentation.yml).

Please search [existing issues](https://github.com/imirfanul/structyl/issues?q=is%3Aissue) first to avoid duplicates.

## 🔒 Security

Never report security vulnerabilities in public issues. See **[SECURITY.md](./SECURITY.md)** and report them privately via a [security advisory](https://github.com/imirfanul/structyl/security/advisories/new).

## 🙌 Contributing

Want to fix or build something? See **[CONTRIBUTING](./.github/CONTRIBUTING.md)** for the workflow, and the **[Code of Conduct](./CODE_OF_CONDUCT.md)** for community expectations.

---

Response times are best-effort — structyl is maintained by volunteers. Clear,
reproducible reports get resolved fastest. Thank you for your patience! 💜
