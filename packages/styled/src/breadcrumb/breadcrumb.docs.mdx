Simple breadcrumb components: `Breadcrumb`, `BreadcrumbItem`, and `BreadcrumbLink`.

```jsx
<Breadcrumb>
  <BreadcrumbItem>
    <BreadcrumbLink href="#">Home</BreadcrumbLink>
  </BreadcrumbItem>
</Breadcrumb>
```
